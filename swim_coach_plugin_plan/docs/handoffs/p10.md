## Runtime flags

```text
SWIM_COACH_OAUTH_ISSUER=https://<tenant>/
SWIM_COACH_OAUTH_RESOURCE=https://<public-mcp>/mcp
SWIM_COACH_MCP_WRITE_ENABLED=true
SWIM_COACH_PLANNING_ENABLED=true
```

Turn off only `SWIM_COACH_PLANNING_ENABLED` to remove the P10 tool and restore
the preceding MCP surface without deleting historical rulesets or runs.
