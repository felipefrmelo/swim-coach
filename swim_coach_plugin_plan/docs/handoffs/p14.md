# Handoff P14

P14 adiciona exclusão física de treino planejado em todas as superfícies. A
solicitação esconde o treino imediatamente e o worker conclui a limpeza Garmin
antes de apagar os registros técnicos locais. A tool pública é
`delete_workout`, usa somente `coach` e depende da confirmação destrutiva do
host, sem proposal/hash/approval.

O gate está concluído: checks locais verdes, plugin 2.1 validado/reinstalado,
schema `000011` implantado, nove tools carregadas e canário real descartável
publicado e excluído no Garmin. Como plugins do Codex são carregados no início
da conversa, use uma nova conversa para exercitar a nova Skill localmente.
