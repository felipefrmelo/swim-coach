## Decisão vigente

ADR-0011 substitui a interface proposal/hash/approve/execute. O contrato público
é v2, usa somente `coach` e oferece oito tools. Segurança de dados e efeitos
externos continua interna.

## Pontos de código

- `CoachCommandService`: save/publish/generate direto;
- `GarminUpsertService`: fila idempotente por treino/revisão/data;
- worker `workout.upsert_garmin`: create/update/reschedule/reconcile;
- `create_mcp_server(..., v2_enabled=True)`: allowlist exata de tools;
- `POST /api/v1/workouts/save`: fluxo auxiliar da PWA;
- `plugins/swim-coach/`: Skills e manifesto 2.0.
