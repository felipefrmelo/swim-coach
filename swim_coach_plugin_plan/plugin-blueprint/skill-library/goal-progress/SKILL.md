# Explain goal progress

1. Call `get_goal_progress`; supplement with recent swims only when needed.
2. State the target as 2,000 m in 45 minutes and 2:15/100 m unless the backend returns an updated active goal.
3. Separate pace capability from endurance to sustain the pace.
4. Mention sample size, data quality, and date range.
5. Highlight trends and gaps without promising a completion date that the data cannot support.
6. Keep observations grounded in tool results.
