# ADR-0006 — PWA sem chat interno no MVP

- **Status:** Accepted
- **Data:** 2026-08-05

## Contexto

A PWA precisa existir, mas um chat interno repetiria o host e exigiria OpenAI API, streaming, memória, custos e guardrails próprios.

## Decisão

PWA oferece dashboard, calendário, editor, atividades, feedback, Garmin, propostas, jobs e privacidade. Não oferece chat no MVP.

## Reconsideração

Somente se existir caso de uso indispensável não atendido pelas superfícies do plugin, documentado por ADR e análise de custo/privacidade.
