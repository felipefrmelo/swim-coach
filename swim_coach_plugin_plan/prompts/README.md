# Prompts de execução

Use um prompt por sessão/fase. Substitua apenas informações concretas do repositório, como branch ou issue. Não cole segredos.

O agente deve ter acesso ao repositório e executar comandos. O prompt não autoriza publicar, enviar dados ou criar efeitos externos além do gate documentado.

Cada prompt manda ler os documentos certos, respeitar escopo, testar, atualizar status e produzir handoff.
